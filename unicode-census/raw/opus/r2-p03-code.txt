```python
def merge_sorted(a, b):
    """Merge two sorted lists into a single sorted list.

    Both inputs must already be sorted in ascending order. The result is a
    new list; neither input is modified. Duplicates are preserved, and the
    merge is stable: when elements compare equal, the one from `a` comes
    first.

    >>> merge_sorted([1, 3, 5], [2, 4, 6])
    [1, 2, 3, 4, 5, 6]
    >>> merge_sorted([], [2, 2, 7])
    [2, 2, 7]
    >>> merge_sorted([1, 4, 4], [4, 9])
    [1, 4, 4, 4, 9]
    """
    merged = []
    i = j = 0
    while i < len(a) and j < len(b):
        if b[j] < a[i]:
            merged.append(b[j])
            j += 1
        else:
            merged.append(a[i])
            i += 1
    merged.extend(a[i:])
    merged.extend(b[j:])
    return merged

```

It runs in O(n + m) time and O(n + m) space. Comparing with `b[j] < a[i]` rather than `a[i] <= b[j]` is what keeps the merge stable while still needing only one comparison per step.
