```python
def merge_sorted(a, b):
    """Merge two sorted lists into a single sorted list.

    Both inputs must already be sorted in ascending order. The result
    is a new list; neither input is modified. Duplicates are kept, and
    equal elements from ``a`` are placed before those from ``b``, so the
    merge is stable.

    Args:
        a: A list sorted in ascending order.
        b: A list sorted in ascending order.

    Returns:
        A new sorted list containing every element of ``a`` and ``b``.

    >>> merge_sorted([1, 3, 5], [2, 4, 6])
    [1, 2, 3, 4, 5, 6]

    >>> merge_sorted([], [1, 2, 3])
    [1, 2, 3]

    >>> merge_sorted([1, 2, 2], [2, 3])
    [1, 2, 2, 2, 3]
    """
    merged = []
    i = j = 0
    while i < len(a) and j < len(b):
        if b[j] < a[i]:
            merged.append(b[j])
            j += 1
        else:
            merged.append(a[i])
            i += 1
    merged.extend(a[i:])
    merged.extend(b[j:])
    return merged

```

The loop walks both lists at once, always taking the smaller head, so it runs in O(len(a) + len(b)) time. Comparing with `b[j] < a[i]` rather than `a[i] <= b[j]` keeps the merge stable while requiring only that elements support `<`.
